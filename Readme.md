# Click The Circle Game

Это простая игра, которую я сделала с помощью **JavaFX** и **Scene Builder**. 
Правила игры простые: игрок должен за ограниченное время (30 секунд) кликать по кругам, которые появляются в случайных местах на игровом поле. 
Цвета и размеры кругов выбираются случайным образом. За обычные круги игрок получает очки, но количество очков зависит от размера круга. Чем меньше круг - тем больше очков, чем больше размер круга тем меньше очков.Когда время заканчивается, появляется окно с результатом игры.
- Красные круги — это ловушки, которые **отнимают очки**.
- **Дизайн** простой и минималистичный.
- Для визуального создания интерфейса (FXML) и логики на Java были выбрала **JavaFX + Scene Builder**.  
- Добавила цвет и шрифт для кнопки и сделала круги цветными.
- **Возникли небольшие трудности** с обеспечением правильного расположения кругов, чтобы они не выходили за границы окна. И с правильной остановкой игры.

### Data Structures and Algorithms

Основные структуры данных.
`score` хранит количество очков, `timeLeft` — оставшееся время,  `Pane gameArea` это контейнер для всех Circles.  
`Circle` — это отдельный объект с заданным радиусом, цветом и координатами (определяются рандомно).  
Таймеры `Timeline` управляют временем и частотой появления новых кругов.

Алгоритмы.  
Таймер (`startTimer()`) уменьшает время каждую секунду и завершает игру, когда оно достигает нуля.
Метод `spawnCircle()` — выбирает случайный размер, цвет (Color) и позицию для нового круга и добавляет его на игровое поле (gameArea).
Дальше `spawnCircle()` — вычисляет очки по формуле (40 - radius) / 5 + 1 и добавляет их к score при клике на обычный круг.
Алгоритм штрафа: `spawnCircle()` — проверяет, красный ли круг (isRed) и вычитает 5 очков при клике по нему.
Методы `spawnCircle()` и обработчик клика — `ScaleTransition` делает плавное появление круга, `FadeTransition` — плавное исчезновение после клика.
`endGame()` останавливает таймеры, очищает игровое поле и показывает окно с итоговым счётом (Alert).
